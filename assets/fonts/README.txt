Fonts used by the game, served from this folder so the page makes no request to Google Fonts.

  Licence: OFL-IBM-Plex.txt (SIL Open Font License 1.1).

The .woff2 files are the Latin subset (U+0000-00FF, general punctuation, a few symbols) as served by Google Fonts on
2026-11-02; they were not modified. The unicode-range in index.html matches that subset. A character outside it falls back
to Impact, Arial Narrow or the system monospace.
