rgpoly-fighter.glb is one character (Character_1_2_2) plus twelve clips from RG Poly's "City Character Pack" (free version),
https://rg-poly.itch.io/cartoon-city-massive-pack-characters
The itch page, read on 2026-11-02, says of the pack: "CC0 Licensed. Free for personal and commercial use, no attribution required."
The zip itself ships no license file, so that page text is the only statement. File used: "Characters Free.zip", 15,300,736 bytes,
sha256 c34b3449aa887e612ce65591f4710308fbaec14b275154f6b8bc461f86143188.
Built in Blender 5.1.1 from the FBX files: the character, the atlas "Texture/City Atlas Map.png" embedded as its base colour
(the FBX points at a texture file that is not in the zip), metallic 0, and these clips as separate animations:
FightM_Idle, FightM_Pose, FightM_Punch_A/B/C, FightM_Combo_A, FightM_Hit_A/B/C, FightM_Death_A, Walk_A, Runing_A.
